# Random Task Generator

**Автор:** Приходько Яна

## Описание программы

Random Task Generator - это консольное приложение для генерации случайных задач различных типов. Программа помогает пользователям получать случайные задания для работы, спорта, учебы, домашних дел и заботы о здоровье.

### Основные возможности

- 🎲 **Генерация случайных задач** - автоматическое создание задач разных типов
- ✏️ **Добавление пользовательских задач** - возможность создавать свои задачи
- 📜 **История задач** - хранение всех сгенерированных и добавленных задач
- 🔍 **Фильтрация** - возможность фильтровать задачи по типу или сложности
- 💾 **Сохранение и загрузка** - работа с JSON файлами для сохранения истории
- 🧪 **ООП архитектура** - использование паттернов Factory, наследования и полиморфизма

## Как запустить приложение

- Python 3.7 или выше
